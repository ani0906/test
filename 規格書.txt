# Vibe Coding 需求規格書：羽翼下的選擇 - 共生之境

## 專案概述
這是一款單頁式 Web App 互動測驗遊戲，旨在透過「雙視角」的情境選擇，讓玩家體驗台灣野生動物（草鴞）與人類在淺山惡地環境中的生存挑戰與決策影響。

## 視覺與風格設定
* **背景主題切換**：
    * **首頁/預設**：深藍色與深墨綠色的融合漸變背景。
    * **草鴞視角 (Owl Theme)**：介面色調為深墨綠色（Dark Forest Green）搭配草鴞眼睛的琥珀金（Amber Gold）強調色，帶有神祕與荒野感。
    * **人類視角 (Human Theme)**：介面色調為深藍科技感（Dark Slate Blue）搭配亮藍色（Sky Blue）強調色，呈現現代與冷靜感。
    * **過渡效果**：主題切換時需有流暢的背景顏色漸變動畫（1秒過渡）。
* **介面設計**：乾淨、沉浸式的卡片風格，文字排版需像生態紀錄片的旁白般具備故事性。
* **響應式設計 (RWD)**：必須完全支援手機（Mobile-first）與電腦螢幕觀看。

## 核心功能與流程

### 1. 首頁 (Start Screen)
* **內容**：顯示主標題「羽翼下的選擇：共生之境」及一段背景簡介。
* **互動**：提供兩個視角選擇按鈕：
    * 「成為 草鴞 🦉」（點擊切換至草鴞主題並開始測驗）
    * 「成為 人類 🚶」（點擊切換至人類主題並開始測驗）

### 2. 測驗進行區 (Game Screen)
* **進度顯示**：畫面上方需有進度條，隨著答題進度流暢推進（例如：1/5 到 5/5）。進度條顏色需跟隨當前主題。
* **題目與選項展示**：
    * 每次顯示一題情境描述（Title）。
    * 下方提供 2 個選項按鈕（Options）。選項需包含具體的行動與背後的潛在影響描述。
* **雙軌題庫與計分系統**：
    * **草鴞線 (5題)**：
        * **情境**：棲地選擇、毒鼠誘惑、流浪犬威脅、築巢地點、寒冬覓食。
        * **計分邏輯**：採用「存活率加權計算」（初始值 1.0，每個選項帶有一個 `< 1.0` 的權重相乘）。
    * **人類線 (5題)**：
        * **情境**：果園鼠患處理、流浪犬餵食、荒地光電開發、除草方式、偶遇受傷鳥類。
        * **計分邏輯**：採用「環境友善積分加總」（初始值 0，每個選項帶有正分或負分相加）。

### 3. 載入動畫 (Loading Screen)
* **觸發時機**：回答完最後一題後。
* **內容**：顯示一個旋轉的 Loading 圈圈。
* **文字提示**：
    * 草鴞線：「正在計算生態存活率與軌跡...」
    * 人類線：「正在評估你的決策對土地的影響...」
* **持續時間**：約 2.2 秒。

### 4. 結局報告卡片 (Result Screen)
* **草鴞結局**：
    * **稱號與描述**：依據最終存活率給予對應的稱號（如：暗夜裡的傳奇獵手、謹慎的荒野隱士、邊緣探索者、草地精靈）。
    * **數據化衝擊**：顯示殘酷的生存數據：「全台僅存不到 500 隻的草鴞中，只有大約 `[計算出的人數]` 隻能跟你一樣做出這些抉擇並存活」。若分數過低，人數強制為 0 且字體變為紅色警告。
* **人類結局**：
    * **稱號與描述**：依據最終積分給予對應的稱號（如：生態的共生守護者、務實的環境平衡者、無心的生態干擾者）。
    * **影響力呈現**：顯示「你的日常決策 `保護了 90% / 維持了 50% / 威脅了 80%` 在地草鴞的棲地與生存機會」。
* **重置功能**：提供「重新選擇命運」按鈕，點擊後清空分數、重置主題，並返回首頁。

## 技術要求
* **單一檔案結構**：所有的 HTML 結構、CSS 樣式表、以及 JavaScript 邏輯必須完全整合在單一個 `index.html` 檔案中，以利直接透過 GitHub Pages 部署。
* **無後端依賴**：所有狀態（進度、分數計算）皆在客戶端（Client-side）透過 JavaScript 變數管理，不需儲存至資料庫。
* **字串處理**：JavaScript 中的題目字串若包含換行，必須使用 `\n`，並在渲染至 HTML 時替換為 `<br><br>` 以避免語法錯誤。
